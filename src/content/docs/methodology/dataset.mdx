The project uses a collection of malware samples to study ransomware-related behaviors and support the development of the proposed defense optimization framework. The dataset is processed through sample validation, duplicate removal, malware classification, sandbox execution, and behavioral report extraction.

---

## Dataset Sources

The project has collected approximately **3,000 malware samples** from multiple sources, including VirusTotal, VirusShare, and samples provided by the project guide.

The collected samples form the initial repository for malware analysis. The dataset is organized to support sample identification, behavioral analysis, and the extraction of triggered signatures for subsequent attack–defense mapping.

---

## Sample Validation and Deduplication

The project uses VirusTotal information to validate the authenticity of collected samples. Duplicate samples are removed using their SHA-256 cryptographic hashes.

SHA-256 hashing provides a consistent identifier for comparing files and detecting identical samples within the repository. Removing duplicate files helps avoid repeatedly analyzing identical binaries and reduces unnecessary duplication in the dataset.

The documented preparation process includes:

1. **Collection:** Collecting malware samples from the identified sources.
2. **Authenticity Validation:** Checking sample authenticity using VirusTotal information.
3. **Deduplication:** Computing SHA-256 hashes to identify and remove duplicate samples.
4. **Repository Organization:** Organizing the remaining samples for further analysis.

---

## Malware Classification

The collected samples are segregated according to their available malware-class information. Online antivirus engines are also used as part of the sample-classification process.

This classification supports the organization of the malware repository and helps identify samples for subsequent analysis. The classification process should retain the available sample identifiers and class labels so that analysis reports can be associated with their corresponding samples.

## Inclusion and Exclusion Criteria

The documented dataset preparation process includes sample collection, VirusTotal-based validation, SHA-256 duplicate removal, and segregation according to malware-class information.

The final experimental dataset consists of the samples that are selected for analysis under the project's configured workflow. The analysis reports and extracted signatures are used to determine which samples provide usable behavioral evidence for the subsequent stages.
